Records are stored in the existing JJ4 room's protected episode JSON through optimistic conditional updates; no new table, credential or per-spouse sharing unlock.
5. SMS feedback **does not** count as independent human certification. It is explicitly labeled `verified-participant-sms`, `participant-feedback-only`. Official 8/10 still needs transcript-backed full ten-dimension review, six non-averagable hard checks, ten independent fictional couples and zero blockers.
6. The five-day open story and Sophia closure remain on the same 4.3 shared event ledger. All production release gates remain as previously defined.
