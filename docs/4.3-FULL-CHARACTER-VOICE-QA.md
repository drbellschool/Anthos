# Anthos 4.3 — Full-character-voice generator, not an AI prefix

**Implementation date:** 2026-11-22  
**Status:** Integrated in draft PR #135, model-backed mocked tests passed. Full real-model quality certification remains BLOCKED.

## Existing flow now

1. Read exact previously committed story facts and the specific coach message.
2. Classify the actual suggestion and character's likelihood of adopting/resisting it; no unverified reported instructions can commit actions.
3. Compute and validate one canonical event; persist a unique event identity; the state and score ledger remain independent of generated wording.
4. **Use the existing Responses API** with the existing configured model/key to write the *entire* Jack/Jill reply as a natural SMS to the private coach. No canned sentence appended. Context includes character flaws, motivations, the actual coaching, pre/post world state, evidence about any committed action, past own-coach replies, developmental tendency, unresolved tension, and source-verified memories.
5. Require exact coach-to-reply grounding anchors in the generated structured output, reject replies that introduce additional actions or unsupported partner reactions, repeat earlier character text, invent repair price, repair completion, another purchase or a new shop call. A benign joke must be attempted or explicitly addressed.
6. On invalid draft, regenerate once with concrete validator feedback; if still invalid/unavailable, use the existing safe fallback and record `replySource`, `replyModelAttempts`, `replyValidationIssue`. Only real canonical actions are scored; a generated sentence cannot award points.
7. Continue using the two existing Jack/Jill conversations, shared event ledger and Insight Atlas; no new Anthos engine, public API, database tables, keys or new AI provider.

**Offline ten-couple pilot** remains deliberately RED: 31 unique messages / 100 (31%), benign joke ignored. The new full-message voice model cannot improve this test unless `OPENAI_API_KEY` is available to its execution environment; it currently runs without a key and intentionally uses fallback.

## Environment finding

The Vercel project currently declares an existing `OPENAI_API_KEY` for **production only**, while the preview has `OPENAI_MODEL` but no preview-scope `OPENAI_API_KEY`. The deployed preview code can run the safer fallback but **cannot demonstrate model-written character dialogue** in that environment. Do **not** silently copy sensitive production secrets into broadly accessible previews or claim this is a live-AI demonstration. `status().voiceMode` reports `full-model` or `verified-fallback` without disclosing credentials; `/pilot-v4/` now displays that diagnostic to the tester.

## The next genuine model-quality proof

Use the already-configured key in a properly isolated, explicitly authorized QA environment (not an unguarded public preview). Rerun the ten frozen couple scripts through the *same 4.3 open-character path with real model generation*, inspect each complete coach-to-character dialogue for creativity, agency, appropriate humor, canonical consistency, and meaningful outcomes; classify validator repairs and fallback rates. The 8/10 rubric remains binding. No full-release claim until this pass, account isolation and the other locked gates are verified.

I finally apologized to Jill for leaving the old microwave broken so long. Now I need to follow through, not give her another speech.” Verified event: Jack apologizes once.
- Coach to Jack: “Make a joke about declaring Saturday a national microwave repair holiday.” → Model-output fixture: “A national microwave repair holiday? That's a strong proposal. Mine would have to include three missed Saturdays and a ceremonial apology to a very patient calendar. I'm not sure Jill would find this funny yet.” No claim of having actually told Jill the joke; no canonical event or character score movement.
- Invalid draft: “I called the repair shop today and they quoted me a $95 repair.” → Rejected; existing canonical state has only a plan, no repair-shop call and no price. Corrected mock message mentions finding a model number and a future call without invented prices.
